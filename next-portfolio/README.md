Next.js portfolio scaffold

This folder (`next-portfolio`) contains a modern Next.js + TailwindCSS starter for your portfolio.

Quick start

1. Change into the folder:

   ```bash
   cd next-portfolio
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run development server:

   ```bash
   npm run dev
   ```

Open http://localhost:3000

Notes & next steps

- This is a lightweight scaffold that reproduces the core sections of your existing static site.
- If you want to reuse your existing `css/`, `js/`, and `images/` assets, I can copy them into `next-portfolio/public` and update pages to use them. Ask me and I'll move them in for you.
- To deploy: push to GitHub and connect to Vercel, or build with `npm run build` and `npm start`.
